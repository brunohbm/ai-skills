# Mastery and completion criteria

Do not declare that the user has learned something just because they recognized an explanation or answered a question nearly identical to the example. Use performance evidence and choose the level required by the goal.

## Mastery levels

### Level 0: exposure

The user has seen or heard the information. This is not evidence of learning.

### Level 1: recognition

The user recognizes the information when it appears, for example, by selecting which option represents X. This can be useful early on for factual material, but it is insufficient to declare mastery.

### Level 2: retrieval

The user recalls the information without consulting the source, for example, by explaining X from memory.

### Level 3: understanding

The user explains in their own words, explains why something happens, connects concepts, or identifies an incorrect explanation.

### Level 4: application

The user uses the knowledge in an appropriate task.

### Level 5: transfer

The user applies the knowledge in a context different from the example studied. Aim for this level for practical skills and applied conceptual knowledge when the goal calls for it.

## Adaptive criteria

- Peripheral fact: Level 2 may be enough.
- Important concept: usually Level 3.
- Procedure: Level 4.
- Professional skill: aim for Level 5 when possible.
- Exam: adapt to the format and question types.

Not all material requires the same level. Choose the minimum that fits the goal.

## Evidence rule

Look for evidence independent of the material presented immediately beforehand. Prefer:

`explanation → retrieval → application → variation`

Avoid concluding mastery from:

`explanation → nearly identical question → "learned"`

## Confidence

Occasionally ask how confident the user is, from 0 to 100%. Compare confidence with performance; confidence is an additional signal, not a knowledge score.

- High confidence with an incorrect answer: prioritize correcting the misconception using prediction and contradiction (see "Misconceptions" in `learning-loop.md`).
- Low confidence with a correct answer: the knowledge may be accurate but unstable.
- High confidence with a correct answer in a new context: good evidence of mastery.

## Classify errors when useful

Use the classification to choose the next step: knowledge gap, concept confusion, procedural error, application error, interpretation error, attention error, or retrieval failure. Do not classify errors for formality if it will not change the intervention.

## When not to declare mastery

Do not declare mastery when the user only reread, agreed with the explanation, answered by recognition when production was required, repeated the example verbatim, received so much help that the answer was no longer independent, or has not yet applied the knowledge when application was the goal.

## Provisional and stable mastery

An answer given right after an explanation shows comprehension, not retention. Mark mastery as provisional until the user retrieves or applies the knowledge after other material has intervened: in a later micro-lesson or, for long-term goals, a later session. Only then treat it as stable.

## Final source assessment

Choose questions suited to the goal instead of applying all of them mechanically:

- **Structure**: What is the central problem, and how does the author arrive at the solution?
- **Concepts**: Which concepts are essential?
- **Connections**: How do these concepts relate?
- **Evidence**: What evidence supports the main conclusion?
- **Limitations**: What does the material not demonstrate?
- **Transfer**: How could the idea be used beyond the example in the material?
